Privacy Policy — GearLab X Expand Pack #1

By Dario Maggiari · Last updated: 3 October 2026 · dario.maggiari@gmail.com

EnglishItaliano

English

GearLab X Expand Pack #1 (EP1) is a separate Android app that transfers an included Bey and Deck configuration archive to GearLab X when the user starts an import. EP1 does not require an account, internet access, or Android runtime permissions for personal data.

EP1 stores the selected language and whether an import completed in local app preferences. During import it copies the included archive to private temporary storage, verifies its SHA-256 digest, and gives GearLab X temporary read access through Android FileProvider. The temporary copy is deleted after the import returns; an interrupted operation may leave it in the app's private cache until Android or the user clears app data. GearLab X handles the imported configurations under its own privacy policy.

EP1 does not send user data to the developer or a remote server. It has no advertising, analytics, or remote telemetry SDK. Buttons to open GearLab X, its Play Store page, or this policy use Android external apps only when the user chooses them; those apps have their own privacy practices.

You may clear EP1's local data in Android settings or uninstall EP1. To remove configurations already imported into GearLab X, use GearLab X's controls; uninstalling EP1 does not remove imported configurations.

This policy will be updated if EP1's behavior changes. For privacy questions, contact dario.maggiari@gmail.com.

Italiano

GearLab X Expand Pack #1 (EP1) è un'app Android separata che trasferisce a GearLab X un archivio incluso di configurazioni Bey e Deck quando l'utente avvia l'importazione. EP1 non richiede account, accesso a Internet o permessi Android runtime per dati personali.

EP1 conserva nelle preferenze locali la lingua scelta e l'avvenuto completamento di un'importazione. Durante l'importazione copia l'archivio in una cache privata, ne verifica l'impronta SHA-256 e concede a GearLab X un accesso temporaneo in lettura tramite Android FileProvider. La copia temporanea viene eliminata al ritorno dall'importazione; se l'operazione si interrompe, può rimanere nella cache privata finché Android o l'utente cancella i dati dell'app. GearLab X gestisce le configurazioni importate secondo la propria informativa privacy.

EP1 non invia dati dell'utente allo sviluppatore o a server remoti. Non contiene pubblicità, analytics o SDK di telemetria remota. I pulsanti per aprire GearLab X, la sua pagina Play Store o questa informativa usano app esterne Android solo su scelta dell'utente; tali app seguono proprie prassi privacy.

Puoi cancellare i dati locali di EP1 dalle impostazioni Android o disinstallarla. Per eliminare configurazioni già importate usa i comandi di GearLab X; disinstallare EP1 non elimina i dati importati.

Questa informativa sarà aggiornata se cambia il funzionamento di EP1. Per domande sulla privacy: dario.maggiari@gmail.com.
